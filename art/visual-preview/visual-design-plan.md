# 小M學習城市：視覺設計預覽規格

## 可沿用的「學生學習群組」規劃

- 以「知識種子研究所＋學習城市」作為所有複習網站的共同入口。
- 完成學習任務獲得知識幣；知識幣只能由學習取得，不連結真實金錢。
- 普通任務獎勵種子扭蛋，單元里程碑獎勵主題盲盒，錯題修復獎勵成長盲盒。
- 重複收藏品轉為星光碎片，並提供保證取得新收藏的友善機制。
- 個人收藏裝飾自己的學習區；全班完成任務共同點亮城市與成長樹。
- 系統記錄單元進度、概念正確率、重試與訂正結果；教師端分為全班即時看板與個別學生報告。
- 不採用公開學生排名，不以停留時間推論學習態度。

## 世界與地圖

- 視角：高角度三分之四等角視圖。
- 母世界：中央知識種子研究所、全班成長樹、收藏博物館、教師觀測站、語文故事劇場、自然溫室、粉紅數學遊樂區。
- 本單元數學區地標：比例打地鼠花園、相等比翻牌亭、果汁調配屋、比值貪食蛇迷宮、速率賽車場、錯題晶石修復工坊。
- 網站初版以可點擊熱區使用；若日後改成角色走動，再建立碰撞、導航與傳送點资料。

## 角色與道具

- 主角：粉紅小狐狸精靈「小M」，奶油白臉部與腹部、深玫瑰披巾、金色比號魔杖。
- 教學 NPC：圓潤花園地鼠，以手持比卡或數字徽章呈現題目。
- 核心收藏：知識幣、完整與破裂的比例晶石、種子膠囊、主題盲盒、成長種子、完成獎章。
- 遊戲道具：翻牌卡背、三色果汁量杯、地鼠洞、貪食蛇頭與身體節、迷你賽車。

## 遊戲畫面

1. 比例打地鼠：敲擊與目標比相等的地鼠。
2. 相等比翻牌：配對原比與相等比。
3. 果汁調配屋：拖曳量杯完成指定配比。
4. 比值貪食蛇：依序吃取正確的晶石或數字段。
5. 速率賽車：以距離與時間計算結果控制車速。
6. 錯題修復工坊：把錯題概念重新操作至晶石完整，才可領取證書與種子獎勵。

## 美術與介面（確認中的黃色簡約版）

- 風格：柔和 2.5D 水粉質感、圓角、觸控友善，適合 10–12 歲但不幼兒化。
- 角色：小M維持草莓粉、奶油白與深玫瑰披巾，作為畫面最明確的角色焦點。
- 場景主色：奶油黃、蜂蜜金、暖白；鼠尾草綠與天空藍只作少量區別色。
- 造型原則：減少建築、花朵、旗幟、晶石與框線裝飾，保留大面積留白、清楚路徑與六個主要地標。
- 狀態提示：愛心代表嘗試機會，星星代表熟練度，晶石代表完成與修復狀態。
- 遊戲回饋：正確以晶石點亮、角色歡呼與柔和粒子呈現；錯誤不使用恐嚇或強烈扣分動畫。

## 預覽資產來源

- 地圖概念：`generate2dmap` 規劃，內建 ImageGen 產生母世界視覺。
- 角色與道具：`generate2dsprite` 規劃，內建 ImageGen 依小M現有角色建立統一素材板。
- 遊戲介面：`imagegen` 產生高完成度玩法視覺板。
- 目前三張圖為設計預覽，不是已切割的正式執行素材；確認方向後才會分離透明圖層、製作實際尺寸與互動版本。
